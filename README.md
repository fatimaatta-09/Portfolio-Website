## 🏁 **Quick Start**

### **1. Clone the repo**

```bash
git clone https://github.com/fatimaatta-09/Portfolio-Website.git
cd Portfolio-Website
```

### **2. Open locally**

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### **3. Push to GitHub**

```bash
git add .
git commit -m "Deploy portfolio"
git push origin main
```

### **4. Enable GitHub Pages**

1. Go to repo **Settings → Pages**
2. Set **Source** to `GitHub Actions`
3. Your site goes live at: `https://YOUR_USERNAME.github.io/Portfolio-Website/`

## 🛠️ **Customize**

Edit **`config.js`** to update:

- **Profile info** (`ABOUT`)
- **Projects** (`PROJECTS`)
- **Skills** (`SKILLS`)
- **Certifications** (`CERTS`)
- **Social links** (`PROFILES`)
- **Terminal commands** (`COMMANDS`)

Save → commit → push → live in ~30 seconds ✨
